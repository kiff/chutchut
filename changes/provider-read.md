- **chutchut can be tafs cloud's mail provider** (`CHUTCHUT_MODE=tafs`). tafs keeps the doors, pairing, holds and the Record; chutchut tells tafs about a message with a signed `email.received` only once its malware scan is clean, and answers tafs's read of it (`GET /emails/receiving/{id}`, behind a read key kept in SSM). A sender check goes to tafs only for a sender proven here, so anyone else can only knock there. In this mode chutchut keeps nothing for good: every message keeps its 30 days.
