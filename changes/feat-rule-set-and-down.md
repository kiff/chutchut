- **The rule can join a rule set that is already active, and `deploy/aws.sh down` takes chutchut back down.** `CHUTCHUT_RULE_SET` names an existing SES rule set for chutchut's rule, so a region that already receives mail keeps doing so. `down` (with `CHUTCHUT_DOWN=yes`) stops the mail first, then removes the triggers, functions, roles, scan, topics and key; it keeps the bucket and the table.
